# Support

Use a bug report for reproducible defects and a feature request for proposed
behavior. Include exact Blender, Unity Editor, URP, Shader Graph, operating
system, B2U add-on/package, and Miku schema versions. Redact private paths and do
not attach assets you cannot redistribute.

The project currently provides community support only, with no response-time or
compatibility SLA. Questions about unsupported editor versions, custom game
shaders, asset extraction, or third-party model rights may be closed or redirected.

Security-sensitive reports must follow [`SECURITY.md`](SECURITY.md), not a public
issue. Node requests should use the node-support template and compare against
[`docs/node-support.md`](docs/node-support.md).

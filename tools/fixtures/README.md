# Tool fixtures

`MikuStandardWrapperSeed.shadergraph` is an internal, MIT-licensed build seed
used only by `tools/build_miku_standard_pbr_wrapper.py`. It is not shipped in
the Unity package and is not a Generic Toon backend. Its history is preserved
from the former MiGR Generic Toon wrapper template so Standard PBR wrapper
generation remains deterministic during the Miku 1.0 identity migration.

# Miku Blender extension 2.1.1 release notes

Miku 2.1.1 adds one English/Simplified-Chinese Blender extension UI that follows
Blender's interface language. Advanced settings now offer 512, 1024, 2048, and
4096 resolutions for generated 2D bake textures; 1024 remains the default.

The release introduces bake request 1.1 and retains read compatibility with
frozen request 1.0. Bake result 1.0, MaterialIR 2.0, Bundle, Unity package
2.2.5, and all Unity public Shader properties are unchanged.

The final deterministic archive is `miku_shader_converter-2.1.1.zip`. Two
canonical builds were byte-identical at SHA-256
`de6e681934c13e82e79069757e8dc63b080b6b84fc28b398c45973fd390bdf0d`.

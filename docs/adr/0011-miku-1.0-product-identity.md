# ADR 0011: Reset the active product identity to Miku 1.0

## Status

Accepted — 2026-07-30

## Context

MiGR has public identifiers across Python modules, Blender extensions, JSON
documents, diagnostics, generated Shader properties, Unity packages, and C#
APIs. A partial rename would create two active identities and ambiguous source
roots.

## Decision

All active implementation and new output uses Miku 1.0. Canonical identities
are `miku`, `miku_blender`, `miku_shader_converter`,
`com.miku.shaderconverter`, `.mikubundle`, `MIKU_*`, `_MIKU_*`, and
`Miku/*`. New documents have 1.0 kinds and
`urn:miku:schema:<kind>:1.0` schema IDs.

MiGR 1.x/2.x documents and serialized asset properties remain accepted only
through explicit legacy readers and migration tools. Old Python imports, C#
namespaces, package IDs, and Shader.Find names are not compatibility surfaces.

## Consequences

The change is source/API breaking and requires migration documentation. Stable
source/material UUIDs, Unity `.meta` GUIDs, and generated role seeds are
preserved to avoid unrelated asset churn.
